# 📊 Data Analytics Interactive Quiz

An interactive web-based simulator designed to help students and professionals prepare for Data Science and Data Analytics job interviews and academic exams. 

The questions are based on the most searched terms globally, covering core foundations, technical SQL/logic challenges, and practical business case studies.

## 🚀 Live Demo
You can try the interactive quiz directly in your browser here:
👉 **[CLICK HERE TO ACCESS THE QUIZ](https://seu-usuario.github.io/nome-do-seu-repositorio/)** *(Substitua este link pelo seu link final do GitHub Pages)*

## 🧠 Topics Covered
- **Block 1: Foundations & Theory** (ETL processes, structured vs. unstructured data, EDA, Outliers, Data Governance).
- **Block 2: Technical & Logical Challenges** (SQL WHERE vs. HAVING, Window Functions, A/B Testing validation, Overfitting, K-Means clustering).
- **Block 3: Practical & Business Cases** (Metric deconstruction, Data Storytelling for executives, LTV/CAC relationships, Cohort analysis, Vanity metrics).

## 🛠️ Technologies Used
- HTML5 (Structured semantic elements)
- CSS3 (Custom dark luxury design palette and responsive layout)
- Vanilla JavaScript (Dynamic DOM manipulation and instant score evaluation)

## 📂 How to Run Locally
1. Clone this repository or download the source code.
2. Open the `index.html` file directly in any modern web browser (Chrome, Edge, Firefox, Safari).
